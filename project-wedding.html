Wedding Invitation & RSVP

Website undangan pernikahan digital interaktif dengan sistem registrasi kehadiran (RSVP), notifikasi email otomatis terintegrasi QR Code Ticket, serta validasi kehadiran (Check-in) tamu di lokasi acara.

Teknologi

Laravel Blade MySQL Laravel Mail QR Code

Tautan Proyek

GitHub Repository

Fitur Utama

  • • Halaman Informasi Acara: Navigasi interaktif peta lokasi (Google Maps API), galeri foto pre-wedding, dan countdown waktu mundur.
  • • Formulir RSVP Tamu: Validasi input nama dan status konfirmasi kehadiran tamu yang tersimpan langsung ke MySQL.
  • • Notifikasi Email Otomatis: Pengiriman email konfirmasi (SMTP Laravel Mail) secara asinkron setelah tamu melakukan registrasi.
  • • Tiket QR Code Dinamis: Pembuatan QR Code unik berisi ID Tamu terenkripsi untuk divalidasi oleh panitia di hari pernikahan.

Bagaimana Sistem Bekerja?

Tamu mengisi form konfirmasi kehadiran (RSVP) di website undangan. Data disimpan di database, lalu sistem memicu event email queue untuk mengirimkan email berisi tiket QR Code. Saat hari pelaksanaan acara, panitia memindai QR Code tamu menggunakan aplikasi pemindai berbasis web. Sistem melakukan validasi token database secara real-time untuk mencatat jam kedatangan tamu dan memblokir tiket ganda.
