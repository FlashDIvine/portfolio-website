Admin Cafe Dashboard

Sistem informasi manajemen internal kafe berbasis web. Memfasilitasi admin untuk mengelola stok menu makanan, penataan klasifikasi kategori, hak akses pengguna, serta pencatatan transaksi secara real-time.

Teknologi

PHP MySQL HTML5 CSS3 JavaScript

Tautan Proyek

Live Demo GitHub Repository

Fitur Utama

  • • Manajemen Menu: Tambah, edit, dan hapus data menu makanan/minuman beserta upload foto menu.
  • • Pengelolaan Kategori: Pengelompokan jenis makanan untuk menyederhanakan filter pencarian menu kafe.
  • • Sistem Transaksi: Pencatatan pesanan kasir secara digital dan penghitungan kalkulasi total harga otomatis.
  • • Dashboard Monitoring: Visualisasi rekap penjualan harian dan total menu terdaftar untuk mempermudah analitik bisnis.

Bagaimana Sistem Bekerja?

Sistem ini berjalan dengan model server-side rendering menggunakan PHP native/Laravel. Admin/Kasir login melalui portal keamanan, kemudian data menu dan transaksi diproses secara langsung melalui query MySQL database. Pengelolaan relasi foreign key antara tabel menu dan kategori memastikan integritas data tetap terjaga saat terjadi penghapusan atau pembaruan.
