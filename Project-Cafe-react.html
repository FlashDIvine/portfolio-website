Cafe App (React)

Aplikasi menu cafe modern dengan antarmuka dinamis dan interaktif. Proyek ini menghubungkan frontend React dengan RESTful API Laravel untuk checkout otomatis ke WhatsApp.

Teknologi

React.js Tailwind CSS Laravel API Fetch API WhatsApp API

Tautan Proyek

Live Demo GitHub Repository

Fitur Utama

  • • Dynamic Menu Fetching: Mengambil menu makanan dan minuman secara real-time dari REST API Laravel.
  • • Interactive UI: Antarmuka yang responsif dan berkinerja tinggi menggunakan React state dan lifecycle hooks.
  • • Shopping Cart System: Manajemen keranjang belanja dinamis yang memproses penambahan, pengurangan, dan penghapusan item pesanan.
  • • WhatsApp Checkout: Konversi data pesanan menjadi pesan teks terstruktur lalu mengarahkan pembeli langsung ke chat WhatsApp.

Bagaimana Sistem Bekerja?

Arsitektur aplikasi ini memisahkan frontend (React) dari backend (Laravel). Saat halaman dibuka, React mengirim HTTP request via Fetch API ke RESTful API Laravel untuk mengambil kategori dan menu aktif. Setelah pengguna menumpuk pesanan di keranjang dan menekan checkout, data diubah menjadi query parameters WhatsApp API untuk membuka pesan otomatis yang terstruktur rapi untuk admin kafe.

Pembelajaran & Kompetensi

  • ✔ Manajemen state global/local di React.js
  • ✔ Integrasi cross-origin resource sharing (CORS) dengan Laravel
  • ✔ Utilitas utility-first CSS menggunakan Tailwind
  • ✔ Integrasi API pihak ketiga (WhatsApp Business API)
