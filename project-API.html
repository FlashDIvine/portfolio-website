API Toko Online

RESTful API yang tangguh untuk sistem e-commerce. Dibangun di atas Laravel, API ini menangani otentikasi token Bearer, validasi payload request, manajemen CRUD produk, serta upload gambar secara aman.

Teknologi

Laravel MySQL REST API Postman Bearer Token

Tautan Proyek

GitHub Repository

Fitur Utama

  • • Bearer Token Authentication: Login pengguna yang menghasilkan API Token unik untuk mengamankan komunikasi data.
  • • Middleware Route Protection: Pencegahan akses ilegal pada endpoint sensitif (menghasilkan respons 401 Unauthorized jika tanpa token).
  • • Full Product CRUD: Operasi lengkap penciptaan (Create), pembacaan (Read), pembaharuan (Update), dan penghapusan (Delete) produk.
  • • Image Upload Handler: Mengamankan proses upload berkas gambar produk menggunakan form-data dan menyimpannya di file system.

Daftar Endpoint API

Method Endpoint Keterangan Otentikasi
POST /api/login Login untuk mengambil Bearer Token Bebas
GET /api/products Mendapatkan list semua produk Wajib
POST /api/products Menambah produk baru & upload gambar Wajib
DELETE /api/products/{id} Menghapus produk berdasarkan ID Wajib

Alur Autentikasi & Respons

1. Proteksi Endpoint (Tanpa Token - 401 Unauthorized)

2. Pengambilan Bearer Token melalui Login

3. Contoh Struktur Output API (GET, POST, & DELETE)

Pembelajaran & Kompetensi

  • ✔ Mekanisme autentikasi API berbasis token keamanan
  • ✔ Manajemen middleware routing untuk enkapsulasi endpoint
  • ✔ Pengolahan data multipart/form-data dan validasi berkas
  • ✔ Penyusunan kode status HTTP (200, 201, 401, 422) sesuai standar REST
